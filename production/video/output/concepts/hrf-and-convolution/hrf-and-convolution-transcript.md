## The HRF and convolution

The H R F and convolution. The hemodynamic response function (H R F) approximates the delayed, smooth bold response that follows brief neural activity. Convolution combines event timing with this response shape to create a model predictor. The predictor should resemble the signal you expect to measure, not an instantaneous event list.
