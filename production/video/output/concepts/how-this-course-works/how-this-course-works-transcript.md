# How this course works

## How this course works

How this course works. Use each lesson as a two-window study session: explanation here, analysis in Neurodesk. The goal is clear: Set up an effective two-window workspace.

## Understand, observe, reproduce

Understand, observe, reproduce. Each workflow is split into a concept, a real interface walkthrough, an independent Neurodesk task, and an output check. The point is not to memorize button positions; it is to understand what information enters and leaves each step. Pause often. Predict what a command or FEAT setting will do before you run it. Then compare the result with the expected output and explain discrepancies in your own words.

## Try this in Neurodesk

Now connect the idea to an observable check. First, place this lesson on one side of your screen. Next, place Neurodesk on the other side. Then, create a notes file for observations and unresolved questions. Record what you observe so the decision remains reviewable.

## What would make this interpretation trustworthy?

Practical labs work best on a computer. Videos and reading work on mobile, but use a desktop or laptop for Neurodesk exercises and side-by-side quality control. A useful self-check is this: When should you look at expected output? After making a prediction and running the step yourself, so the comparison tests understanding rather than copying.

## Carry the reasoning into the next step

To recap: First, predict before running a step. Next, record what you observe, especially when it differs from the example. Before continuing, make sure you can explain this objective: Set up an effective two-window workspace.
