# Getting started with Neurodesk

## Getting started with Neurodesk

Getting started with Neurodesk. Choose Play, EDU, or an institutional environment and verify that F S L is available. The goal is clear: Choose an appropriate Neurodesk access route.

## A reproducible software environment

A reproducible software environment. Neurodesk packages neuroimaging applications in consistent environments. Neurodesk Play is broadly accessible; Neurodesk EDU may be provided by a course or institution; a local installation is optional and has higher hardware requirements. Files saved only inside temporary browser sessions may disappear. Use the persistent storage location provided by your environment. The base terminal is useful for general Linux work; an F S L terminal starts with the F S L software environment already loaded.

## What would make this interpretation trustworthy?

F S L command not found? You may be in the base terminal rather than the F S L application terminal. Open the F S L tile, or load the F S L module if your environment supports modules. A useful self-check is this: What is the operational difference between the base terminal and an F S L terminal? The F S L terminal has the F S L environment loaded; the base terminal is a general shell and may not find F S L commands until a module is loaded.
