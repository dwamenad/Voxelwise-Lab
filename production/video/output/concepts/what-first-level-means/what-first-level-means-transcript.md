## What first-level analysis means

What first-level analysis means. First-level analysis models a single run from a single participant. It estimates how well the predicted response for each explanatory variable accounts for the observed bold signal at every voxel. The output is not a group conclusion. It is a set of participant/run-specific parameter estimates and contrasts that can later feed Level 2 or Level 3 models. Keep the unit of analysis explicit when naming outputs.
