## Experimental timing files

Experimental timing files. An F S L three-column timing file has one event per row: onset in seconds, duration in seconds, and amplitude. Each condition normally has its own file. Timing is relative to the start of the modeled run. Units, missing events, and condition labels must be checked against the BIDS events.tsv file. A syntactically valid file can still encode the wrong experiment.
