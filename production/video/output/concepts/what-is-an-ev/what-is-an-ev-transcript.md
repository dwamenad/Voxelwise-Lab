## What is an explanatory variable?

What is an explanatory variable? An explanatory variable (E V) represents a pattern expected to explain some variation in the data. Task events, parametric values, motion estimates, and other confounds can all become E V's, but their interpretations differ. FEAT begins with the event timing you specify, convolves task E V's with a hemodynamic response, and may add temporal derivatives. Each resulting column consumes model degrees of freedom, so include predictors for a reason—not simply because they are available.
