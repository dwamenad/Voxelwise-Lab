# What is FSL?

## What is FSL?

What is F S L? Meet the collection of tools used to inspect, preprocess, model, and report M R I data. The goal is clear: Describe F S L as a suite rather than one application.

## FSL is a toolkit, not a single program

F S L is a toolkit, not a single program. F S L—the F M R I B Software Library—is a collection of command-line tools and graphical interfaces for M R I analysis. FEAT handles functional M R I modeling, F S L Eyes displays images, and utilities such as F S L info, F S L stats, and F S L maths inspect or transform data. A typical workflow moves between tools. You might inspect a raw bold image in F S L Eyes, configure a model in FEAT, run it, then return to F S L Eyes to check registration and statistical maps. Learning F S L therefore means learning both the scientific purpose of each step and the output it produces.
