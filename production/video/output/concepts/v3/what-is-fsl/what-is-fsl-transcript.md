# What is FSL?

## One toolkit, many jobs

FSL is a collection of focused neuroimaging tools. Instead of forcing every task into one program, it gives you different tools for viewing images, checking metadata, transforming data, fitting models, and reviewing results. Learning FSL means knowing which tool answers the question in front of you.

## The job selects the tool

Start with the scientific job. FSLEyes is for visual inspection. FEAT configures and evaluates fMRI models. Command-line utilities expose precise metadata, statistics, and image operations. These tools share a workflow, but they do not provide interchangeable evidence.

## A report records the chain

This FEAT report is one example of FSL's division of labor. FEAT organizes the model and its outputs, while visual checks often continue in the report and in FSLEyes. A completed report proves that software ran; it does not by itself prove that the analysis is scientifically valid.

## Execution is not validation

A command can succeed on the wrong file. A model can finish with a poor design. An overlay can look plausible in one slice and fail elsewhere. Treat every FSL output as evidence to inspect, not as an automatic conclusion.

## Match tool to question

FSL is a suite of related tools. Choose the tool by the job, preserve the connection between steps, and inspect what each output actually demonstrates. Successful computation never replaces visual and scientific quality control.
